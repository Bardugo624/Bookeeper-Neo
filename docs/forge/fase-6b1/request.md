# Richiesta

Regola permanente del proprietario: "Come sempre, prima integra, poi tutti i P3 poi prossima fase".

Run **6B1**: i sedici difetti P3 lasciati dal revisore nel run 6B, più sei difetti d'aspetto trovati guardando desktop e telefono con una libreria di famiglia. Implementatore `sonnet`, revisore `opus`, una riprova automatica, niente Fractal.

Difetti d'aspetto:
1. Desktop, invito: la scadenza appare come "Scade tra 10079:59" (minuti e secondi di un invito di 7 giorni).
2. Desktop, invito: "Sul telefono: inquadra il QR" anche quando il QR non c'è.
3. Desktop: la voce "Persone" della barra laterale ha l'icona di un segnaposto.
4. Desktop: la sezione "Notifiche" delle impostazioni ha l'icona di un avviso.
5. PWA, prestiti: una persona della libreria ha l'icona degli scaffali.
6. PWA, scansione: "Si trova in: Libreria grande, ripiano 1" senza il posto, diversa dalla frase di "Dove si trova".
