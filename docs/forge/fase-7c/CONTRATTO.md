# Contratto del run 7C

- Nessuna dipendenza nuova. Nessuna modifica a `ops/` né ai workflow `vps-*.yml`.
- La versione è una sola, `2.0.0`, ovunque la release la legge o la mostra: workspace Rust, configurazione di Tauri, pacchetti npm delle app e dei pacchetti, istantanea OpenAPI.
- Le note di una versione sono la sua sezione in `CHANGELOG.md` (`## [2.0.0] - aaaa-mm-gg`), senza il titolo. Le stesse note vanno nella release su GitHub e nel manifesto degli aggiornamenti, dove l'app le mostra in "Vedi novità" con il suo interprete di Markdown (titoli `##`/`###`, elenchi, grassetto e corsivo, codice in linea, collegamenti).
